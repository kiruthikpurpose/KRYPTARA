# Full proofs

## Setup

Fix a finite set of atoms P, |P| = n. A **policy** is a monotone Boolean function f: 2^P -> {0,1}
(monotone: S ⊆ T implies f(S) ≤ f(T)). Write S for subsets of P, identified with their indicator
bit-strings. A **compromise structure** 𝒜c is a finite set of subsets of P ("compromise seeds"); a
**loss structure** 𝒜l is likewise a finite set of subsets ("loss seeds").

**Definition (safe).** f is safe with respect to 𝒜c if f(A) = 0 for every A ∈ 𝒜c.
*Interpretation:* if the adversary holds exactly the atoms in some declared compromise seed A, they
cannot present evidence set A itself and have f authorise it.

**Definition (live).** f is live with respect to 𝒜l if f(P ∖ L) = 1 for every L ∈ 𝒜l.
*Interpretation:* if the atoms in some declared loss seed L are lost, the survivors P∖L can still
satisfy f.

## Lemma 1 (U is the pointwise-largest safe monotone function)

Define U(S) = 1 iff S ⊄ A for every A ∈ 𝒜c (equivalently: S is not a subset of any compromise seed).

**Claim:** U is monotone, U is safe, and every safe monotone f satisfies f ≤ U.

**Proof.**
*Monotone.* Suppose S ⊆ T and U(S) = 1, i.e. S ⊄ A for every A. If U(T) = 0 then T ⊆ A for some A;
since S ⊆ T, S ⊆ A too, contradicting U(S)=1. So U(T) = 1. Hence U is monotone.

*Safe.* For any A ∈ 𝒜c, A ⊆ A trivially, so by definition U(A) = 0. Thus U(A) = 0 for every A ∈ 𝒜c:
U is safe.

*Pointwise-largest.* Let f be any safe monotone function and suppose, for contradiction, f(S) = 1
for some S with U(S) = 0. U(S) = 0 means S ⊆ A for some A ∈ 𝒜c. Monotonicity of f gives
f(A) ≥ f(S) = 1, i.e. f(A) = 1 — contradicting that f is safe (f(A) must be 0). So f(S) = 1 implies
U(S) = 1, i.e. f ≤ U. ∎

## Lemma 2 (Lo is the pointwise-smallest live monotone function)

Define Lo(S) = 1 iff S ⊇ P∖L for some L ∈ 𝒜l (equivalently: S is an upward extension of some
loss-survivor set). Lo is exactly the upward closure, in the subset lattice, of the generator set
{P∖L : L ∈ 𝒜l}.

**Claim:** Lo is monotone, Lo is live, and every live monotone f satisfies f ≥ Lo.

**Proof.**
*Monotone.* The upward closure of any set of generators is monotone by construction: if S ⊇ P∖L for
some L and S ⊆ T, then T ⊇ S ⊇ P∖L, so T is also in the closure.

*Live.* For any L ∈ 𝒜l, P∖L ⊇ P∖L trivially, so Lo(P∖L) = 1 by definition. Thus Lo is live.

*Pointwise-smallest.* Let f be any live monotone function and let S be any point with Lo(S) = 1,
i.e. S ⊇ P∖L for some L ∈ 𝒜l. Liveness gives f(P∖L) = 1. Monotonicity gives f(S) ≥ f(P∖L) = 1, so
f(S) = 1 = Lo(S). Hence Lo ≤ f pointwise wherever Lo = 1, and trivially elsewhere (Lo=0 puts no
constraint); so Lo ≤ f everywhere. ∎

## Theorem 1 (the interval theorem), assembled from Lemmas 1-2

(i) f safe ⇔ f ≤ U. (⇐) direction is immediate from U being safe and f ≤ U, since f(A) ≤ U(A) = 0
for every A. (⇒) direction is Lemma 1's pointwise-largest claim.

(ii) f live ⇔ f ≥ Lo. (⇐) is immediate from Lo being live. (⇒) is Lemma 2's pointwise-smallest claim.

(iii) The safe-and-live monotone functions are exactly those with Lo ≤ f ≤ U — immediate from (i)
and (ii) conjoined. Since U and Lo are themselves both monotone (Lemmas 1, 2), every f with
Lo ≤ f ≤ U is automatically monotone wherever Lo and U agree, and the interval [Lo, U] in the
Boolean lattice is non-empty and well-defined whenever Lo ≤ U pointwise.

(iv) **[Lo, U] ≠ ∅ iff A ∪ L ≠ P for every A ∈ 𝒜c, L ∈ 𝒜l** ("mixed Q²").

**Proof of (iv).** [Lo,U] ≠ ∅ iff Lo ≤ U pointwise (the interval is non-empty in a lattice iff its
lower bound doesn't exceed its upper bound anywhere). Lo ≤ U pointwise iff, for every generator
P∖L of Lo's upward closure, U(P∖L) = 1 (since U is monotone and Lo is generated by upward closure,
checking U dominates Lo at the generators suffices — if U(P∖L)=1 for every L, then for any S ⊇ P∖L,
monotonicity of U gives U(S) ≥ U(P∖L) = 1, so U dominates Lo everywhere; conversely if some
U(P∖L)=0, Lo(P∖L)=1 > U(P∖L)=0 directly violates Lo≤U at that point).
U(P∖L) = 1 iff P∖L ⊄ A for every A ∈ 𝒜c (definition of U), i.e. iff for every A there is some atom
in A that is NOT in P∖L, i.e. that atom is in L. Equivalently: A ∩ L ≠ ∅ is NOT what's required —
re-deriving carefully: P∖L ⊆ A would mean every atom outside L is inside A, i.e. A ⊇ P∖L, i.e.
A ∪ L ⊇ P, i.e. (since A, L ⊆ P) A ∪ L = P. So U(P∖L) = 0 exactly when A ∪ L = P for that A. Hence
U(P∖L) = 1 for every L iff A ∪ L ≠ P for every A and every L. ∎

## Theorem 2 (the class-count law), full detail

Partition P into k disjoint classes C_1, ..., C_k (a "class" fault compromises or loses an entire
C_i at once, not a partial subset — this is the simplification Theorem 2 makes that Theorem 1 does
not need). 𝒜c = {unions of any t of the C_i}, 𝒜l = {unions of any s of the C_i}.

**Theorem 2.** A safe-and-live monotone policy exists over this structure iff k ≥ t + s + 1.

**Proof, (⇐) direction: construction.** Suppose k ≥ t+s+1. Define f_thresh(S) = 1 iff S intersects
at least t+1 of the k classes (i.e. S contains at least one atom from each of at least t+1 distinct
C_i's). f_thresh is monotone (adding atoms to S cannot decrease the count of classes it touches).

*f_thresh is safe:* any compromise seed A is a union of exactly t classes, so A touches exactly t
classes — f_thresh(A) requires touching ≥ t+1, so f_thresh(A) = 0. Safe.

*f_thresh is live:* any loss seed L is a union of exactly s classes; P∖L then contains all atoms of
the remaining k−s classes, so P∖L touches exactly k−s classes. Since k ≥ t+s+1, k−s ≥ t+1, so
f_thresh(P∖L) = 1 (touches at least t+1 classes). Live.

So f_thresh witnesses a safe-and-live policy: the interval is non-empty.

**Proof, (⇒) direction: covering argument.** Suppose k ≤ t+s. Since k ≤ t+s, the k classes can be
split into a first group of min(t, k) classes and a second group of the remaining k − min(t,k)
classes, with the second group's size at most s (because the second group has k − min(t,k) ≤ k ≤
t+s classes, and if t ≤ k then the second group has exactly k−t ≤ s classes by hypothesis; if t ≥ k
the first group alone already exhausts all k classes and the construction is even easier, taking
A to be all k classes and L empty). Let A be the union of the first group (at most t classes — pad
with any unused classes if fewer than t are needed, since 𝒜c allows ANY t classes, not exactly a
specific t) and L be the union of the second group (at most s classes, similarly padded). By
construction every one of the k classes lies in A or in L (or both, if padding caused overlap,
which only strengthens the conclusion), so A ∪ L = P. Theorem 1(iv)'s mixed-Q² condition then fails
for this (A, L) pair — A ∈ 𝒜c, L ∈ 𝒜l, A ∪ L = P — so [Lo, U] = ∅: no safe-and-live policy exists. ∎

**Machine cross-check [M].** `models/interval.py` [3] brute-forces this exact claim over k ∈ 1..6,
t,s ∈ 0..2 (with k≥t,s so the partition is well-defined): 0 disagreements between the k≥t+s+1
prediction and the Theorem-1-based exact computation. `models/exhaustive_small.py` (item 4)
independently re-confirms the underlying Theorem 1 computation itself is correct for n=3,4 against
ALL monotone functions (not a sample) and ALL k≤2 fault structures (not a sample).

## Theorem 3 (every recovery path is an attack path), full detail

Let a device have several named **authority paths** g (e.g. "normal operation", "recovery"), each
with its own safe-and-live policy drawn from a shared k-class structure, with its own tolerance
pair (t(g), s(g)) satisfying Theorem 2's bound t(g) + s(g) ≤ k − 1 individually. Say a path reaches
**full control** if, once authorised, the actor can re-key or re-label arbitrarily (i.e. this path's
authorisation is sufficient to rewrite the whole policy).

Define t_eff = min_g t(g) (the device's overall compromise tolerance is only as strong as its
weakest full-control path) and s_max = max_g s(g) (its recovery ability is as generous as its most
permissive full-control path).

**Theorem 3.** t_eff + s_max ≤ k − 1.

**Proof.** Let g* be the path achieving s_max, i.e. s(g*) = s_max. Since g* is itself a valid
safe-and-live policy over the same k-class structure, Theorem 2 applies to it directly:
a safe-and-live policy for g* exists only because k ≥ t(g*) + s(g*) + 1, i.e.
t(g*) ≤ k − 1 − s(g*) = k − 1 − s_max. Since t_eff = min_g t(g) ≤ t(g*) (t_eff is a minimum over
ALL paths including g*), we get t_eff ≤ t(g*) ≤ k − 1 − s_max, i.e. t_eff + s_max ≤ k − 1. ∎

**Why this is not a free lunch.** The proof shows the bound is forced by Theorem 2 applied to the
SAME g* that provides the generous recovery tolerance s_max — there is no way to keep that
tolerance while independently hardening a different path's t(g), because any full-control path,
including the "easy recovery" one, inherits the same k-class ceiling. This is the formal version of
"a backdoor is a backdoor regardless of how the front door is labelled."
