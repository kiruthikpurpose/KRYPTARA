# Requirements (normative)

**Level:** L2. Keywords MUST/SHOULD per RFC 2119. "Verified by" names a test or states **not yet verified**. Legacy requirements (221 `FR-`/`NFR-` rows in `research-archive/streams/R_requirements.md`; also UC-, SP-, ADV-, CA-, RD- IDs of other artifact types in the same file) have a **mechanical first-pass reconciliation plus a small manually-verified set** against this set: `docs/research/legacy-requirements-reconciliation.md` (regenerate with `scripts/reconcile_legacy_requirements.py`), 2 manually verified covered, 11 likely covered (keyword match, unverified), 62 out of scope for the kernel today, 146 gap candidates still needing a human triage decision. This set covers the kernel only; most legacy items concern fleet orchestration, updates, migration, enclaves, ownership-transfer protocol, and certification evidence that are Phase 2+ on the roadmap, not yet built.
