# ADR-001: Preserve the name KRYPTARA and document its limits

**Status:** Accepted  
**Date:** 2026-11-09  
**Legacy IDs:** Legacy: D-21, D-37

## Context
Owner named the project on 2026-11-09. No source uses the name. 'Yielding' and 'Paradigm' lack established technical meaning.

## Decision
Keep the name; record proposed readings in docs/vision-and-scope.md; make no paradigm claim.

## Consequences
Name is stable; claims stay bounded.

## Alternatives considered
Rename (rejected: owner decision); invent a scientific meaning (rejected: dishonest)
