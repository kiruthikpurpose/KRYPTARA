# ADR-006: Publicity as exposure, via witnessed receipts

**Status:** Accepted  
**Date:** 2026-11-09  
**Legacy IDs:** Legacy: D-26, J-25

## Context
Makes covert authority visible and vetoable.

## Decision
≥2 independent logs; C2SP formats; RFC 9162 proofs; devices never query logs.

## Consequences
Does not prevent; depends on log/witness institutions (R-2).

## Alternatives considered
Gateway-held receipts; witnesses as preventive
