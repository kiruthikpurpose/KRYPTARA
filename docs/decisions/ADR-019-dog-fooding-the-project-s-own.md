# ADR-019: Dog-fooding: the project's own releases are governed by the same tiers, logs

**Status:** Accepted
**Date:** 2026-11-09
**Legacy IDs:** Legacy: D-36

## Context
Credibility and continuous testing of the governance tools

## Decision
Dog-fooding: the project's own releases are governed by the same tiers, logs and ceremonies

## Consequences
Direct migration of a legacy Rev 4 decision (D-36, status NEW in the legacy record)
into ADR form; no new analysis was done in this migration. See `docs/decisions/legacy-decision-
record.md` for the original table row and `docs/theory/red-team-r2-findings.md` for any R2 finding
that may have since amended it.

## Alternatives considered
Conventional release signing
