# Decisions

ADR-001..015 are the authoritative decisions (L2). `legacy-decision-record.md` holds the full Rev 4 D/C/X/J tables (D-21..D-37 etc.), which remain valid unless an ADR supersedes them. Mapping: each ADR lists its legacy IDs. Legacy IDs D-01..D-20, C-xx, X-xx, J-xx not listed in an ADR are **not yet migrated**.
