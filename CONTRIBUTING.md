# Contributing

1. Every claim needs an evidence class and, if Derived, a runnable check.
2. Add or change a decision through an ADR; do not edit accepted ADRs, supersede them.
3. Run `./scripts/run_all_checks.sh` and `python3 scripts/audit_docs.py` before committing.
4. No empty placeholder files; no claims about unimplemented code.
5. Keep hardware content defensive.
